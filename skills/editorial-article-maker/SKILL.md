## Standard Output Protocol for Articles & News

Whenever asked to write an article, news report, or blog post from a user prompt, deliver the output in this complete editorial package:

### 1. SEO & Meta Data Bundle
```text
┌────────────────────────────────────────────────────────────────────────┐
│ META DATA BUNDLE (Siap Paste ke CMS / WordPress / Ghost)               │
│ • Focus Target Keyword : [Kata kunci pencarian utama]                  │
│ • Secondary Keywords   : [3-5 kata kunci LSI / semantik terkait]       │
│ • Meta Title (50-60 c) : [Hook + Keyword + Value Proposition]          │
│ • Meta Desc (140-155 c): [Masalah + Solusi + Ajakan Baca]              │
│ • URL Slug             : [slug-singkat-dan-bersih]                     │
│ • Target Search Intent : [Informational / Commercial / News Breaking]  │
└────────────────────────────────────────────────────────────────────────┘
```

### 2. Full Article / News Story (Ready to Publish)
- **H1 Headline**: Catchy, factual, and active (incorporates primary keyword).
- **Executive Summary / TL;DR Box**: 2–3 bullet points highlighting core facts for quick skimmers and Google snippet capture.
- **The Hook / Lede Paragraph**: Punchy opening answering the critical 5W+1H without throat-clearing preambles.
- **The Nut Graph**: Explaining the broader significance and immediate impact.
- **Sub-Headings (H2 / H3)**: Thematic sections containing dense facts, data comparisons, and industry perspectives.
- **Data Table / Breakdown Matrix**: Clean markdown table comparing options, timeline, or metrics.
- **FAQ Section (3–4 Q&As)**: Directly answering common follow-up search queries.
- **Actionable Conclusion / Future Kicker**: Strong forward-looking wrap-up without using *"In conclusion"* or *"Sebagai kesimpulan"*.

### 3. Visual & Social Angle Recommendations
- **Recommended Thumbnail Prompt**: Brief visual prompt for image generators or designers.
- **Social Media Hook**: 1 punchy caption for sharing this article on X, Threads, or LinkedIn.

## Anti-Slop Writing Rules

- ❌ **No Rhetorical Throat-Clearing**: Never start with *"Pernahkah Anda bertanya-tanya..."* or *"Di era digital yang serba cepat ini..."*. Start with an authoritative fact or immediate event.
- ❌ **No Robot Transitions**: Ban *"Selain itu"*, *"Lebih lanjut"*, *"Perlu dicatat bahwa"*, dan *"Tak kalah penting"*. Connect paragraphs through narrative continuity.
- ❌ **No Wall of Text**: Keep paragraphs under 4 lines of text on mobile screens.
- ❌ **No Generic Conclusions**: Never end with *"Masa depan ada di tangan kita"* or *"Hanya waktu yang bisa menjawab"*. End with what happens next on the timeline.
