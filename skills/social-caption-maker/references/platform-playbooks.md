# Platform-Specific Caption Playbooks

Tactical algorithms, formatting layouts, and Social SEO keyword placement across Instagram, TikTok, X (Twitter), Threads, and LinkedIn.

---

## 1. Instagram Playbook (Reels & Carousel Feeds)

### Algorithm Priority:
1. **Saves** & **Shares** (Weights 3x higher than likes).
2. **Explore Page SEO**: Instagram indexes the first 30 words and OCR text in the video.

### Template Architecture:
```text
[HOOK: 1-line curiosity or value drop - under 70 chars]

[SPACER LINE BREAK]

[CORE PAYLOAD: 3 to 5 scannable bullets with clean dashes or numbers]
• Point 1: Specific actionable insight
• Point 2: Tangible outcome / tool name
• Point 3: Pro tip most people overlook

[SPACER LINE BREAK]

[ENGAGEMENT TRIGGER: Save or debate callout]
Save postingan ini biar gampang dicari pas lo butuh nanti 📌

[SPACER LINE BREAK]

[SOCIAL SEO BLOCK: 1-2 natural sentences containing target search queries]
Belajar dasar desain UI UX modern dan tips layout website bento grid untuk pemula.

[NICHE TAGS: 3 to 5 targeted keywords only - no spam tags]
#uiuxdesign #webdesign #frontendtips #desainweb
```

---

## 2. TikTok Playbook (FYP & Search Indexing)

### Algorithm Priority:
1. **Completion Rate** & **Watch Time**.
2. **Search Bar Keyword Ranking** (TikTok is now Gen Z's primary search engine).

### Social SEO Rules for TikTok:
- **Spoken Word = On-Screen Text = Caption Keyword**: The algorithm transcribes video audio and matches it with caption words.
- Keep the caption under 150 characters with the primary search query embedded naturally:

### Template Architecture:
```text
Trik rahasia bikin layout website keliatan mahal tanpa ribet pake CSS bento. Detail kode dan tipsnya ada di video! ⚡

#webdev #uiux #tutorialcoding #belajarcoding
```

## 3. X / Twitter Playbook (Viral Impressions & Bookmarks)

### Algorithm Priority:
1. **Bookmarks** (Highest signal of value).
2. **Quote Retweets** & **Replies**.
3. **External Link Penalty**: Never put an external link in the main tweet; put it in the auto-reply/thread below.

### The Bookmark-Bait Tweet Format:
```text
Stop memorizing complex CSS grid syntax.

Here are 5 modern layout rules that will instantly make your UI look 10x cleaner:

1. Asymmetrical Bento (2:1 hero card ratio)
2. Fluid typography with clamp()
3. 24px border radius with subtle 0.08 opacity borders
4. Deep ambient blur instead of flat gray boxes
5. Tabular numbers for financial metrics

Bookmark this for your next project. 📌
```

## 4. Threads Playbook (Casual, Relatable & Banter)

### Algorithm Priority:
- High reply-to-post ratio and organic conversational threads.
- Threads rewards casual, unpolished, thought-provoking statements:

### Example Formats:
> *"Semakin kesini, UI web yang bagus itu bukan yang rame animasi muter-muter, tapi yang cepet kebuka dan teksnya gampang dibaca.*
>
> *Setuju gak atau lo masih tim website penuh partikel 3D?"*

## 5. LinkedIn Playbook (Modern Founder / Creator)

### Algorithm Priority:
- Dwell time + meaningful commentary (comments with > 10 words).
- Zero corporate cliché (*"I am thrilled to announce..."* &rarr; immediate reach death).

### The Modern Narrative Architecture:
```text
We redesigned our onboarding UI last month.

Zero flashy 3D illustrations.
Zero generic stock photos.
Just 3 clean Bento cards and a 1-click Google OAuth button.

The result?
Our signup conversion jumped from 14% to 27% in 10 days.

Here is what we learned about modern user behavior:
1. Users don't read paragraphs; they scan headlines.
2. Every extra form input cuts conversion by 8%.
3. Visual clarity beats aesthetic complexity every single time.

What is one design experiment that surprised you this year?
```
